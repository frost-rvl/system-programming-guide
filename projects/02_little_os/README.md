# Little OS

My project following the [Little OS Book](https://littleosbook.github.io/).

## Requirements

You need `stage2_eltorito` to build the ISO: it is part of GRUB Legacy (GPL) and is not included in this repo.\
  Follow the Little OS Book to get it, or build it from the GRUB Legacy 0.97 source.\
